Publish to GitHub Pages — real hosting, real search visibility

This publishes your bundle straight to a real GitHub-hosted site — no Netlify, no Cloudflare, and you never have to touch the GitHub website yourself. It needs one thing from you: a personal access token, which is basically a temporary password that lets this page act on your GitHub account.

Don't have one? Generate one here ↗ — tick the repo scope, set an expiration, click Generate, then paste it above. It's only ever sent directly from this page to GitHub, and only lives in this tab's memory — it's gone the moment you close or reload.
Your site will live at yourname.github.io/my-cool-site

Live pages usually take 1–2 minutes to build the first time — if it 404s immediately, just wait a bit and refresh.
